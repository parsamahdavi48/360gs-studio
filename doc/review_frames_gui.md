# Step 2 Frame Review GUI

The integrated GUI Step 2 embeds the `review_frames.py` review widget and applies the final keep/drop result with `apply_frame_decisions.py`.

## Purpose

Step 2 is where extracted frames are checked before mask generation and SfM.

- Inspect extracted frames in single-preview or thumbnail-list mode
- Confirm frames flagged by pair analysis, blur detection, weak tracking, or quick extraction
- Change `keep` / `drop` decisions in `selected_frames.csv`
- Press `Apply` to delete drop-marked images from `images/` and rewrite the CSV to keep-only rows

## Inputs

- `Scene Folder`: folder that contains `selected_frames.csv` and `images/`
- `selected_frames.csv`: generated by Step 1 or `extract_frames.py`
- `images/`: extracted frames referenced by the CSV

When the scene folder is selected, Step 2 automatically loads `selected_frames.csv`. If the CSV is missing, the pane shows a placeholder instead.

## Review Views

- `Single Preview`: inspect one frame at a time.
- `Thumbnail List`: scan many frames and select multiple frames using Windows Explorer-style selection.
- `90° Perspective Preview`: for 360° equirectangular images, switch the single preview to a square 90° FOV perspective view. Drag to look around and use the wheel for 2D zoom.

In thumbnail mode, the keep/drop button and reset button operate on the selected thumbnails. If no thumbnail selection exists, they operate on the current frame. The bottom ribbon on each thumbnail shows a shortened version of the current advisory label.

## Keep/Drop Decisions

The flag button toggles the current frame or selected thumbnails between `keep` and `drop`. Changes are written to `selected_frames.csv` immediately. The reset button restores the loaded decision for the current selection.

`Apply` is enabled when:

- any decision differs from the loaded CSV state, or
- drop-marked images still exist in `images/`

If `Apply` is disabled, there is nothing pending to write into the image folder and you can continue to Step 3.

## Advisory Labels

Step 2 labels are not a separate scoring system. They explain why a frame was selected, dropped, added, or marked for review.

Display follows the current `decision` first. `drop` rows use red `Drop:` labels, kept quality concerns use yellow `Review:` labels, analysis-added frames use blue `Added:` labels, quick extraction uses a purple `Quick:` label, and normal kept frames use a green `OK:` label. Thumbnail view uses the same category color in the bottom ribbon with a shorter label; keep/drop border colors are not used.

| Label | Meaning |
| --- | --- |
| `Drop: possible blur` | `drop` row. Dropped because blur may weaken SfM |
| `Drop: similar frame` | `drop` row. Dropped because it is too similar to the previous kept frame |
| `Drop: manually excluded` | `drop` row. Manually switched to Drop in Step 2 |
| `Review: possible blur` | Kept row, but blur may weaken SfM |
| `Review: low texture` | Kept row, but SfM features may be weak |
| `Review: weak feature tracking` | Kept row, but pair tracking confidence may be weak |
| `Added: viewpoint change` | Added before the fixed cadence because viewpoint change was useful |
| `Added: preserved spacing` | Added to keep the gap between kept frames from growing too large |
| `Quick: extracted at the specified interval` | The frame came from quick fixed-interval extraction with no pair analysis |
| `OK: kept` | Normal kept frame |

Use `Next Review Target` / `Previous Review Target` to jump through rows whose `status` is not `ok`.

## Apply

Pressing `Apply` runs:

```bash
python apply_frame_decisions.py <scene_dir> --finalize-in-place
```

If `Back up to images_backup/ before Apply` is enabled, Step 2 adds:

```bash
--backup-dir images_backup
```

Apply does the following:

- deletes drop-marked images from `images/`
- preserves filenames for kept images
- rewrites `selected_frames.csv` to keep-only rows
- writes `selected_frames.before_finalize.csv`
- writes `selected_frames_keep.csv`
- refreshes the embedded review view after success

Without the image backup option, deleted drop images cannot be restored from Step 2. The CSV backup is still created.

## Shortcuts

- `Left` / `Right`: previous / next frame in single-preview mode
- `F` / `Shift+F`: next / previous review target
- `Space`: toggle keep/drop
- `0`: reset preview zoom
