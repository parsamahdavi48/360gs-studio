# Step 2 フレーム確認GUI

Step 2 は、Step 1で抽出したフレームを見て、Step 3のマスク生成と、その後のMetashapeまたはSphereSfMへ進める画像だけを残す画面です。Step 1の解析で付いた `追加`、`除外`、`要確認` ラベルや、シーン取り込みで登録された画像の `外部` ラベルを確認し、必要なら採用/除外を手動で切り替えます。

最後に `適用` を押すと、除外フレームを `images/` から外します。採用フレームのファイル名は既定では維持しますが、マスクやStep 4出力を作る前なら `採用画像を連番化` で連番名へ整理できます。ここで残した `images/` がStep 3のマスク生成と、MetashapeまたはSphereSfMのSfM入力になります。

## まず見ること

| やりたいこと | 見る場所 |
| --- | --- |
| 抽出結果をざっと眺めたい | `サムネイル一覧` |
| ブレや細部を確認したい | `1枚プレビュー` |
| 360°画像を通常カメラのように見たい | `90°パース表示` |
| 除外予定や品質注意のフレームだけ見たい | サムネイルフィルター / `次の確認対象` / `前の確認対象` |
| フレームを残す/外す判断を変えたい | 旗アイコンの採用/除外ボタン |
| マスクやStep 4の前に採用画像を連番化したい | `採用画像を連番化` |
| 変更を実際の `images/` に反映したい | `適用` |

まずはサムネイル一覧で全体の密度を見て、サムネイルフィルターで `除外のみ`、`要確認のみ`、`除外 + 要確認` に絞りながら確認するのが効率的です。視点変化、ブレ置換、間隔維持で追加されたフレームも巡回したい場合は `追加フレームも巡回` をONにします。

## 基本操作

1. Step 1完了後、Step 2を開きます。
2. サムネイル一覧で、フレームの密度や大きなブレを見ます。
3. サムネイルフィルターまたは `次の確認対象` で、除外予定や品質注意のフレームを順番に確認します。
4. 1枚プレビューで必要なフレームを詳しく見ます。360°画像では `90°パース表示` に切り替えると細部を確認しやすくなります。
5. 残したいフレームは `採用`、不要なフレームは `除外` にします。
6. 必要なら、マスクやStep 4出力を作る前に `採用画像を連番化` をONにします。
7. 判断が終わったら `適用` を押します。
8. Step 3へ進みます。

採用/除外の判断は画面上ですぐ保持されます。ただし、`images/` から除外画像を実際に外すのは `適用` を押したときです。

## 表示の使い分け

### サムネイル一覧

多数のフレームを一覧し、撮影の密度、ブレ、同じようなフレームの連続を確認する表示です。Windows Explorerのように、クリック、Shiftクリック、Ctrlクリックで複数選択できます。

複数選択した状態で採用/除外を押すと、選択中のフレームにまとめて反映されます。選択がない場合は、現在表示中の1枚だけに作用します。

ヘッダーのサムネイルフィルターでは、一覧を `除外のみ`、`要確認のみ`、`除外 + 要確認` に絞り込めます。絞り込み中でも採用/除外の変更は同じCSVに保存され、`全フレーム` に戻すと全体表示になります。

### 1枚プレビュー

細部、ブレ、人物の写り込み、スティッチ境界などを確認する表示です。`Left` / `Right` で前後に移動できます。

### 90°パース表示

360°エクイレクタングラー画像を、正方形の90°FOVパース表示に切り替えます。ドラッグで視線方向を動かし、ホイールで表示中画像を2Dズームできます。

## 確認ラベルの意味

Step 2のラベルは、別の品質スコアではありません。そのフレームが採用、除外、追加、要確認になっている理由です。

| ラベル | どう見るか |
| --- | --- |
| `OK: 採用中` | 通常の採用フレーム |
| `クイック: 指定間隔で抽出` | クイック抽出由来。解析ラベルはない |
| `追加: 視点変化を補完` | 固定間隔の前でも有用な視点変化があり追加された |
| `追加: ブレ候補を置換` | ブレの可能性がある候補の近くから、より使いやすい代替フレームとして追加された |
| `追加: 間隔の空きすぎを防止` | 採用間隔が空きすぎないよう安全側で残された |
| `要確認: ブレの可能性` | 採用中だがブレの可能性があり、目視確認したほうがよい |
| `要確認: 低テクスチャ` | 採用中だがSfM特徴点が弱い可能性がある |
| `要確認: 特徴点が弱い可能性` | 採用中だがペア間の追跡が弱い可能性がある |
| `除外: 似たフレーム` | 直前採用フレームと似ているため除外予定 |
| `除外: ブレ` | ブレの可能性が高いため除外予定 |
| `除外: 手動で除外` | ユーザーが除外に切り替えた |
| `外部: 取り込み済み画像` | シーン取り込みや外部画像追加で登録された画像 |

サムネイル一覧では、各画像の下部帯に短縮ラベルと分類色を表示します。除外、要確認、追加採用、クイック抽出、外部取り込み、通常採用を色で見分けられます。

## 採用/除外の決め方

残すか迷ったら、後段のSfMでカメラ位置を推定する役に立つかで判断します。

- ブレが強く、特徴点が弱そうなフレームは除外します。
- ほぼ同じ位置で似たフレームが連続している場合は、間引いても構いません。
- 視点が少し違い、近距離物体の見え方が変わっているフレームは残します。
- 360°画像では、パース表示で床、壁、柱、文字、細い線などを確認します。
- 迷うフレームは残してもよいです。Step 3のマスクやSfM結果で問題が出る場合に戻って調整します。

## 適用

`適用` は、画面上の採用/除外判断を実際の画像フォルダへ反映する処理です。

適用前にはバックアップが作られるため、誤って外した画像が必要になった場合も後から戻せます。

適用すると次を行います。

- 除外にした画像を `images/` から外す
- 採用した画像は既定では現在のファイル名のまま残す
- `採用画像を連番化` がONなら、採用した画像を `frame_000001` から始まる連番名に整理する
- 連番化しても画像形式は変えない
- 成功後、Step 2の表示を再読み込みする

### 採用画像を連番化

Step 3のマスク生成やStep 4の出力を作る前に、画像名を整理したい場合だけ使います。採用した画像を現在の並び順で連番名にし、画像形式は維持します。

すでにマスク生成やStep 4の変換を実行済みのシーンでは、このオプションは選べません。既存のマスクや変換結果が古い画像名を参照して壊れるのを避けるためです。

外した画像が必要になった場合は、レビュー用バックアップから手動で戻せます。

## よくある判断

- 画像フォルダへ反映する変更がない場合は、追加操作は不要です。そのままStep 3へ進めます。
- `除外: 似たフレーム` が多いだけなら、すべて確認する必要はありません。密度が十分ならそのまま適用できます。
- `要確認: ブレの可能性` は必ず目視します。問題なければ採用のままで構いません。
- Step 1をやり直したい場合は、Step 1で `リセットして上書き` を選んで再抽出します。

## ショートカット

- `Left` / `Right`: 1枚表示で前/次のフレーム
- `F` / `Shift+F`: 次/前の問題候補。`追加フレームも巡回` をONにすると追加採用ラベルも含めます。
- `Space`: 採用/除外を切り替え
- `0`: 表示倍率をリセット
