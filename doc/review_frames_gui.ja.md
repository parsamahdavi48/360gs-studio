# Step 2 フレーム確認GUI

Step 2 は、Step 1で抽出したフレームを見て、Step 3のマスク生成と、その後のMetashapeまたはSphereSfMへ進める画像だけを残す画面です。Step 1の解析で付いた `追加`、`除外`、`要確認` ラベルを確認し、必要なら採用/除外を手動で切り替えます。

最後に `適用` を押すと、除外フレームを `images/` から外し、`_stechdrive/frames/selected_frames.csv` を採用フレームだけに確定します。ここで確定した `images/` がStep 3のマスク生成と、MetashapeまたはSphereSfMのSfM入力になります。

## 起動

```bat
run_gui.bat --scene .\scene01
```

起動後、ワークフロー左側の `Step 2: フレーム確認` を開きます。シーンフォルダに `_stechdrive/frames/selected_frames.csv` があれば自動で読み込みます。

中央パネルのヘッダー右端にある `?` ヘルプアイコンから、このStepのGitHubドキュメントを開けます。GUIの表示言語が日本語なら日本語版、英語なら英語版を開きます。

## まず見ること

| やりたいこと | 見る場所 |
| --- | --- |
| 抽出結果をざっと眺めたい | `サムネイル一覧` |
| ブレや細部を確認したい | `1枚プレビュー` |
| 360°画像を通常カメラのように見たい | `90°パース表示` |
| Step 1が要確認にしたフレームだけ見たい | `次の確認対象` / `前の確認対象` |
| フレームを残す/外す判断を変えたい | 旗アイコンの採用/除外ボタン |
| 変更を実際の `images/` に反映したい | `適用` |

まずはサムネイル一覧で全体の密度を見て、`要確認` や `除外` のフレームだけを順番に確認するのが効率的です。

## 基本操作

1. Step 1完了後、Step 2を開きます。
2. サムネイル一覧で、フレームの密度や大きなブレを見ます。
3. `次の確認対象` で、Step 1が印を付けたフレームを順番に確認します。
4. 1枚プレビューで必要なフレームを詳しく見ます。360°画像では `90°パース表示` に切り替えると細部を確認しやすくなります。
5. 残したいフレームは `採用`、不要なフレームは `除外` にします。
6. 判断が終わったら `適用` を押します。
7. Step 3へ進みます。

採用/除外の変更は `_stechdrive/frames/selected_frames.csv` に即時保存されます。ただし、`images/` から除外画像を実際に消すのは `適用` を押したときです。

## 表示の使い分け

### サムネイル一覧

多数のフレームを一覧し、撮影の密度、ブレ、同じようなフレームの連続を確認する表示です。Windows Explorerのように、クリック、Shiftクリック、Ctrlクリックで複数選択できます。

複数選択した状態で採用/除外を押すと、選択中のフレームにまとめて反映されます。選択がない場合は、現在表示中の1枚だけに作用します。

### 1枚プレビュー

細部、ブレ、人物の写り込み、スティッチ境界などを確認する表示です。`Left` / `Right` で前後に移動できます。

### 90°パース表示

360°エクイレクタングラー画像を、正方形の90°FOVパース表示に切り替えます。ドラッグで視線方向を動かし、ホイールで表示中画像を2Dズームできます。

## 確認ラベルの意味

Step 2のラベルは、別の品質スコアではありません。そのフレームが採用、除外、追加、要確認になっている理由です。

| ラベル | どう見るか |
| --- | --- |
| `OK: 採用中` | 通常の採用フレーム |
| `クイック: 指定間隔で抽出` | クイック抽出由来。解析ラベルはない |
| `追加: 視点変化を補完` | 固定間隔の前でも有用な視点変化があり追加された |
| `追加: 間隔の空きすぎを防止` | 採用間隔が空きすぎないよう安全側で残された |
| `要確認: ブレの可能性` | 採用中だがブレの可能性がある |
| `要確認: 低テクスチャ` | 採用中だがSfM特徴点が弱い可能性がある |
| `要確認: 特徴点が弱い可能性` | 採用中だがペア間の追跡が弱い可能性がある |
| `除外: 似たフレーム` | 直前採用フレームと似ているため除外予定 |
| `除外: ブレの可能性` | ブレの可能性が高いため除外予定 |
| `除外: 手動で除外` | ユーザーが除外に切り替えた |

赤系は除外、黄系は採用中の要確認、青系は追加採用、紫系はクイック抽出、緑系はOKです。サムネイル一覧では同じ分類色の下部帯に短縮ラベルを表示します。

## 採用/除外の決め方

残すか迷ったら、後段のSfMでカメラ位置を推定する役に立つかで判断します。

- ブレが強く、特徴点が弱そうなフレームは除外します。
- ほぼ同じ位置で似たフレームが連続している場合は、間引いても構いません。
- 視点が少し違い、近距離物体の見え方が変わっているフレームは残します。
- 360°画像では、パース表示で床、壁、柱、文字、細い線などを確認します。
- 迷うフレームは残してもよいです。Step 3のマスクやSfM結果で問題が出る場合に戻って調整します。

## 適用

`適用` は、画面上の採用/除外判断を実際の画像フォルダへ反映する処理です。

内部では次を実行します。

```bash
python apply_frame_decisions.py <scene_dir> --finalize-in-place
```

`適用前に _stechdrive/frames/backups/images/ にバックアップ` がONの場合は、除外前の画像を `_stechdrive/frames/backups/images/` に保存します。

適用すると次を行います。

- `drop` の画像を `images/` から削除する
- `keep` の画像ファイル名は維持する
- `_stechdrive/frames/selected_frames.csv` を採用行だけに書き換える
- `_stechdrive/frames/backups/selected_frames.before_finalize.csv` と `_stechdrive/frames/selected_frames_keep.csv` を作る
- 成功後、Step 2の表示を再読み込みする

画像バックアップをONにしない場合、削除した除外画像はStep 2から復元できません。CSVバックアップは常に作成されます。

## よくある判断

- `適用` が無効なら、画像フォルダに反映する変更は残っていません。そのままStep 3へ進めます。
- `除外: 似たフレーム` が多いだけなら、すべて確認する必要はありません。密度が十分ならそのまま適用できます。
- `要確認: ブレの可能性` は必ず目視します。問題なければ採用のままで構いません。
- Step 1をやり直したい場合は、Step 1で `リセットして上書き` を選んで再抽出します。

## ショートカット

- `Left` / `Right`: 1枚表示で前/次のフレーム
- `F` / `Shift+F`: 次/前の確認対象
- `Space`: 採用/除外を切り替え
- `0`: 表示倍率をリセット
