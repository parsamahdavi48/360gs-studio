# Step 2 フレーム確認GUI

統合GUIのStep 2は、`review_frames.py` の確認ウィジェットを埋め込み、最後の適用処理で `apply_frame_decisions.py` を実行します。

## 目的

Step 2は、マスク生成やSfMへ進む前に抽出フレームを確認する工程です。

- 抽出フレームを1枚表示またはサムネイル一覧で確認する
- ペア解析、ブレ検出、弱追跡、クイック抽出などで付いた確認ラベルを見る
- `selected_frames.csv` の `keep` / `drop` 判定を変更する
- `適用` を押して、除外フレームを `images/` から削除し、CSVを採用行だけに確定する

## 入力

- `シーンフォルダ`: `selected_frames.csv` と `images/` を含むフォルダ
- `selected_frames.csv`: Step 1または `extract_frames.py` が作成したCSV
- `images/`: CSVから参照される抽出画像

シーンフォルダを選ぶと、Step 2は `selected_frames.csv` を自動で読み込みます。CSVがない場合は、未読み込みの案内が表示されます。

## 確認ビュー

- `1枚プレビュー`: 1枚ずつ確認します。
- `サムネイル一覧`: 多数のフレームを一覧し、Windows Explorer式の複数選択でまとめて確認します。
- `90°パース表示`: 360度エクイレクタングラー画像を、正方形の90度FOVパース表示に切り替えます。ドラッグで視線を動かし、ホイールで2Dズームできます。

サムネイル一覧では、採用/除外ボタンとリセットボタンは選択中のサムネイルにまとめて作用します。選択がない場合は現在フレームだけに作用します。サムネイル下部の帯には、現在の確認ラベルを短くした分類が表示されます。

## 採用/除外

旗アイコンのボタンで、現在フレームまたは選択中サムネイルの `keep` / `drop` を切り替えます。変更は `selected_frames.csv` に即時保存されます。リセットボタンは、読み込み時点の判定へ戻します。

`適用` が有効になる条件は次のどちらかです。

- 読み込み時点から採用/除外の変更がある
- `drop` になっている画像がまだ `images/` に残っている

`適用` が無効なら、画像フォルダへ反映する変更は残っていません。そのままStep 3へ進めます。

## 確認ラベル

Step 2のラベルは、別の品質スコアではありません。そのフレームが採用、除外、追加、要確認になっている理由を表示するものです。

表示は現在の `decision` を優先します。`drop` の行は赤系の `除外:` ラベルになり、採用中の品質注意は黄系の `要確認:`、解析で追加採用された行は青系の `追加:`、クイック抽出は紫系の `クイック:`、通常採用は緑系の `OK:` で表示されます。サムネイル一覧では同じ分類色の下部帯に短縮ラベルを表示し、採用/除外の枠色は使いません。

| ラベル | 意味 |
| --- | --- |
| `除外: ブレの可能性` | `drop` の行。ブレの可能性があるため除外予定 |
| `除外: 似たフレーム` | `drop` の行。直前採用フレームと似ているため除外予定 |
| `除外: 手動で除外` | `drop` の行。Step 2でユーザーが除外に切り替えた行 |
| `要確認: ブレの可能性` | 採用中だが、ブレの可能性がある |
| `要確認: 低テクスチャ` | 採用中だが、SfM特徴点が弱い可能性がある |
| `要確認: 特徴点が弱い可能性` | 採用中だが、ペア間の特徴点追跡が弱い可能性がある |
| `追加: 視点変化を補完` | 固定間隔の前でも視点変化が大きいため追加採用された |
| `追加: 間隔の空きすぎを防止` | 採用間隔が空きすぎないように安全側で追加採用された |
| `クイック: 指定間隔で抽出` | クイック抽出で作られたフレーム。ペア解析は行っていない |
| `OK: 採用中` | 通常の採用フレーム |

`次の確認対象` / `前の確認対象` で、`status` が `ok` 以外の行を順番に巡回できます。

## 適用

`適用` を押すと、次のコマンドを実行します。

```bash
python apply_frame_decisions.py <scene_dir> --finalize-in-place
```

`適用前に images_backup/ にバックアップ` がONの場合は、次のオプションも付きます。

```bash
--backup-dir images_backup
```

適用時に行うこと:

- `drop` の画像を `images/` から削除する
- `keep` の画像ファイル名は維持する
- `selected_frames.csv` を採用行だけに書き換える
- `selected_frames.before_finalize.csv` を作る
- `selected_frames_keep.csv` を作る
- 成功後、Step 2の確認ビューを再読み込みする

画像バックアップをONにしない場合、削除した除外画像はStep 2から復元できません。CSVバックアップは常に作成されます。

## ショートカット

- `Left` / `Right`: 1枚表示で前/次のフレーム
- `F` / `Shift+F`: 次/前の確認対象
- `Space`: 採用/除外を切り替え
- `0`: 表示倍率をリセット
