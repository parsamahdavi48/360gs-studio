# シーン取り込み

`シーン取り込み` は、すでに画像、マスク、データセットが入っているフォルダを、このGUIで続きから扱えるようにする操作です。

新しくフレーム抽出や変換をやり直すための機能ではありません。既存の成果物を確認、マスク、SfM、データセット作成、学習起動の画面から選べる状態に戻したいときに使います。

## 使う場面

| 状況 | 使い方 |
| --- | --- |
| 別PCや別ドライブからシーンフォルダを持ってきた | フォルダを取り込んで、このGUIで作業を再開します。 |
| 既に `images/` や `masks/` がある | 画像とマスクを現在のシーン素材として登録します。 |
| 既に `output/` にデータセットがある | Step 5やStep 6で選べる候補として登録します。 |
| 手作業で画像やマスクを追加した | 取り込み直して、現在のフォルダ内容をGUIに反映します。 |

通常の新規作業では、Step 1で入力ソースを追加して進めます。既存フォルダを再開したい場合だけシーン取り込みを使います。

## 取り込み前に確認すること

- 画像はシーンフォルダ直下の `images/` に入れておきます。
- マスクがある場合は `masks/` に入れておきます。白が使用、黒が除外です。
- Step 5で作ったデータセットがある場合は `output/` 配下に残しておきます。
- 画像名を変えた場合は、マスクやデータセット内の参照と対応しているか確認します。

取り込みは実ファイルを削除しません。シーンフォルダの中身を見直して、このGUIで扱うための登録情報を作り直します。

## 操作

1. `シーンフォルダ` 欄の横にある三本線のメニューを開きます。
2. `シーン取り込み...` を選びます。
3. 取り込むシーンフォルダを選びます。
4. 完了後、Step 2、Step 3、Step 4、Step 5、Step 6で登録内容を確認します。

`シーンフォルダを開く...` はフォルダをエクスプローラーで開く操作です。既存素材をGUIに登録したい場合は `シーン取り込み...` を使います。

## 取り込み後に見るところ

| 画面 | 確認すること |
| --- | --- |
| Step 2 レビュー | `images/` の画像がレビュー対象として表示されるか |
| Step 3 マスク | 既存マスクが認識されているか、追加生成が必要か |
| Step 4 SfM | 既存のSfM結果を使うか、このアプリからSfMするか |
| Step 5 データセット | `output/` 内の既存データセットを使うか、作り直すか |
| Step 6 学習 | 学習アプリに渡すデータセットが期待通りに選ばれているか |

警告が出た場合は、まず画像とマスクの対応、データセット内の画像参照、点群ファイルの有無を確認します。警告は「使えない」という意味ではなく、後工程で確認したほうがよい候補です。

## 再取り込み

同じフォルダを再度取り込むと、GUI上の登録内容は現在のフォルダ状態に合わせて更新されます。

| やりたいこと | 再取り込みの判断 |
| --- | --- |
| 画像やマスクを手で追加した | 再取り込みして反映します。 |
| Step 5の出力データセットを手で入れ替えた | 再取り込みして候補を更新します。 |
| GUI上の選択だけ変えたい | 再取り込みは不要です。各Stepで選択します。 |

再取り込みしても、`images/`、`masks/`、`output/` の実ファイルは削除されません。

## キャンセル

取り込み中はキャンセルできます。大量の画像や大きなデータセットがある場合は時間がかかることがあります。

キャンセルした場合は、途中までの登録内容を採用せず、取り込み前の状態を保ちます。
