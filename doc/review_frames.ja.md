# review_frames.py - 抽出フレーム確認GUI

## 概要

`review_frames.py` は、抽出済みフレームを確認し、`_stechdrive/frames/selected_frames.csv` の `decision` 列を `keep` / `drop` に編集する単体PySide6 GUIです。

統合GUIのStep 2も同じ確認ウィジェットを使っています。統合GUIでの「適用」まで含めた流れは [review_frames_gui.ja.md](review_frames_gui.ja.md) を参照してください。

## 必要なもの

- `PySide6`

## 使い方

```bash
python review_frames.py ./scene01
```

CSVファイル名が異なる場合:

```bash
python review_frames.py ./scene01 --csv selected_frames.csv
```

## キーボード操作

- `Left` / `Right`: 1枚表示で前後のフレームへ移動。サムネイル一覧ではサムネイル一覧側がフォーカスを持ち、矢印キーは表示中のサムネイル選択を動かす
- `F` / `Shift+F`: 次/前の確認対象フレームへ移動
- `Space`: 採用/除外を切り替え
- `0`: 表示倍率をリセット
- `Q`: ウィンドウを閉じる

## 動作

- CSVの `output_file` を読み、対応する画像を表示します。
- ヘッダーのアイコンで、1枚プレビューとサムネイル一覧を切り替えられます。
- 1枚プレビューでは、360度エクイレクタングラー画像を90度FOVのパース表示に切り替えられます。パース表示中はドラッグで視点を動かし、ホイールで2Dズームできます。利用可能な環境ではOpenGL/GPU表示を使い、失敗した場合はCPU描画へフォールバックします。
- サムネイル一覧では、下部の色付き帯に確認ラベルの短縮表示を出します。採用/除外の枠色は使いません。
- サムネイルフィルターで、一覧を `除外のみ`、`要確認のみ`、`除外 + 要確認` に絞り込めます。
- サムネイル選択はWindows Explorer式です。`Ctrl` クリック、`Ctrl+Shift` クリック、`Shift` クリックで複数選択できます。
- サムネイル一覧で採用/除外ボタンを押すと、選択中の複数フレームへまとめて反映します。
- リセットボタンは、選択フレームの `decision` をCSV読み込み時の状態へ戻します。
- サムネイルをダブルクリックすると、そのフレームの1枚プレビューへ戻ります。
- `status` が `ok` 以外の行を確認対象として巡回できます。
- 採用/除外を変更すると、同じCSVへ即時保存します。
- スコア、`status`、インデックスなど、`decision` 以外の列は保持します。

## 確認対象ラベル

`extract_frames.py` のペア解析結果と現在の `decision` に応じて、画面下部とサムネイルに確認ラベルが表示されます。`drop` の行は赤系の `除外:`、採用中の品質注意は黄系の `要確認:`、追加採用は青系の `追加:`、クイック抽出は紫系の `クイック:`、通常採用は緑系の `OK:` です。`F` / `Shift+F` の巡回は通常、除外予定や品質注意だけを対象にします。`追加フレームも巡回` をONにすると、追加採用ラベルも含めます。

- `除外: ブレ`: ブレの可能性があるため除外予定の行
- `除外: 似たフレーム`: 直前採用フレームと似ているため除外予定の行
- `除外: 手動で除外`: Step 2でユーザーが除外に切り替えた行
- `要確認: ブレの可能性`: 採用中だが、ブレの可能性があり目視確認したほうがよい行
- `要確認: 低テクスチャ`: SfM特徴点が弱い可能性がある採用行
- `要確認: 特徴点が弱い可能性`: ペア間の特徴点追跡が弱い可能性がある採用行
- `追加: 視点変化を補完`: 固定間隔の前でも視点変化が大きいため追加採用された行
- `追加: 間隔の空きすぎを防止`: 最大間隔を超えないように安全側で追加採用した行
- `クイック: 指定間隔で抽出`: クイック抽出で作られた行
- `OK: 採用中`: 通常の採用行
