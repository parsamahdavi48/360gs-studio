# استخراج فریم

منبع ویدئویی یا پوشهٔ تصاویر را اضافه کنید، پوشهٔ پروژه را تعیین کنید و فاصلهٔ استخراج را انتخاب کنید. برای ویدئوی ۳۶۰ درجه، نوع تصویر را equirectangular تنظیم کنید. عملیات اصلی فریم‌ها را در `images/` می‌نویسد و فرادادهٔ منبع را برای مراحل بعد نگه می‌دارد.

برای توضیحات فنی کامل، [راهنمای انگلیسی](extract_frames_gui.md) را ببینید.
