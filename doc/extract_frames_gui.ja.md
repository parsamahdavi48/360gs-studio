# フレーム抽出GUI パラメータ解説

このGUIは、360度動画からMetashape SfM向けのエクイレクタングラー静止画を抽出します。現在の基本方針は `固定間隔` です。必要に応じて `変化補正` をONにすると、固定間隔を基準にしながら、変化が少ない候補をスキップし、変化が大きい区間には追加候補を入れます。

## 前提

- 解析と実画像書き出しは別処理です。
- 解析は `解析幅` で縮小したグレースケール画像で行います。
- `images/` に保存される画像は元動画解像度のままです。
- `即時推定` は固定間隔だけで計算した基準枚数です。`変化補正` ON時の実際の枚数は解析後に増減します。

## 固定間隔

### `間隔`

- 単位: 秒
- 意味: 何秒ごとに1枚を基準候補にするか
- 内部計算: `step = round(interval_sec * fps)`
- UI範囲: `0.05〜60.0` 秒
- 操作: 数値欄を横ドラッグして調整可能
- 例: 30fpsで `0.8` 秒なら約24フレームごと

値を上げると基準枚数は減り、値を下げると増えます。3DGS用のSfMでは、まず固定間隔で時間方向のカバレッジを安定させる方が扱いやすいです。

## 変化補正

`変化補正` は固定間隔の追加オプションです。抽出の主軸は固定間隔のままにして、解析結果から以下を行います。

- 低変化スキップ: 直前に採用したフレームから十分に変化していない候補を `thinned` として除外
- 高変化追加: 固定間隔の間で、変化が大きいフレームを `smart_added` として追加
- 特徴点モーション評価: 輝度差だけでなく、疎な特徴点追跡による移動量も使い、SfMで意味のある視差を拾いやすくする

### `最小`

- 単位: 秒
- 意味: 追加候補を入れるときの最小間隔
- 内部計算: `min_gap_frames = round(min_gap_sec * fps)`
- デフォルト: `0.25` 秒

どれだけ変化が大きくても、この間隔より近い追加候補は入りません。

### `最大`

- 単位: 秒
- 意味: 低変化スキップで採用フレームが空きすぎないようにする安全間隔
- 内部計算: `max_gap_frames = round(max_gap_sec * fps)`
- デフォルト: `2.0` 秒

変化が少ない区間でも、この間隔以上に離れる候補は安全側で残します。

## 解析幅

### `解析幅`

- 単位: ピクセル
- 意味: 変化量、特徴点モーション、SfM向け品質スコアを計算する解析解像度の横幅
- デフォルト: `1920`

値を上げると細かい特徴を見やすくなりますが解析は遅くなります。値を下げると高速になりますが、細かい変化や特徴点を見落としやすくなります。

## SfM品質確認

詳細設定の `SfM品質確認` は、固定間隔と変化補正で決まった候補に対して、SfM向けの品質確認と代替フレーム選択だけを行います。低変化スキップは `変化補正` 側の処理です。

### `品質確認スコア`

- 単位: 0.0〜1.0 の正規化スコア
- 計算: 特徴点数、特徴点の画面内分布、シャープネス、コントラスト、白飛び/黒つぶれペナルティの合成値
- 意味: 代替フレーム選択後の品質スコアがこの値未満の場合、Step 2の確認対象として `fallback_keep` を記録
- デフォルト: `0.35`

### `代替フレーム選択基準`

- 単位: 0.0〜1.0 の正規化スコア差
- 計算: `候補フレームの品質スコア - 元フレームの品質スコア`
- 意味: 近傍の代替フレームを採用するために必要な品質改善量
- デフォルト: `0.08`

値を下げると代替フレーム選択が積極的になり、値を上げると明確に良い候補だけを採用します。

## 画像形式

### `JPEG品質`

- 単位: ffmpegの `-q:v`
- UI範囲: `1〜31`
- 操作: 数値欄を横ドラッグして調整可能
- 重要: 数値が小さいほど高画質・大容量
- デフォルト: `2`

## 確認の見方

Step 2では `selected_frames.csv` の `status` をもとに確認対象を表示します。

- `ok`: 通常採用
- `smart_added`: 変化補正で追加された候補
- `replaced`: 近傍のSfM向けフレームに代替済み
- `fallback_keep`: 代替後も品質スコアが基準未満
- `thinned`: 低変化区間として除外中

まずは固定間隔 `0.8〜1.0` 秒、`変化補正` ONのまま1本抽出し、Step 2で `smart_added` と `thinned` の出方を見て調整するのが安全です。
