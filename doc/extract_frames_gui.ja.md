# フレーム抽出GUI パラメータ解説

このGUIは、360度動画からMetashape SfM向けのエクイレクタングラー静止画を抽出します。現在の基本方針は `固定間隔` です。必要に応じて `変化補正` をONにすると、固定間隔を基準にしながら、変化が少ない候補をスキップし、変化が大きい区間には追加候補を入れます。

## 前提

- 解析と実画像書き出しは別処理です。
- 解析は `解析幅` で縮小したグレースケール画像で行います。
- `images/` に保存される画像は元動画解像度のままです。
- `即時推定` は固定間隔だけで計算した基準枚数です。`変化補正` ON時の実際の枚数は解析後に増減します。
- `クイック抽出` ON時は、短いテストSfM向けに固定間隔の書き出しを優先します。変化補正とペア解析による確認情報は作りません。
- シーンフォルダのパスに日本語などの非ASCII文字、極端に長いパス、制御文字や `"` が含まれる場合、統合GUIは実行前に停止します。英数字だけの短い作業パスを指定してください。

## 固定間隔

### `間隔`

- 単位: 秒
- 意味: 何秒ごとに1枚を基準候補にするか
- 内部計算: `step = round(interval_sec * fps)`
- UI範囲: `0.05〜60.0` 秒
- 操作: 数値欄を横ドラッグして調整可能
- 例: 30fpsで `0.8` 秒なら約24フレームごと

値を上げると基準枚数は減り、値を下げると増えます。3DGS用のSfMでは、まず固定間隔で時間方向のカバレッジを安定させる方が扱いやすいです。

### `クイック抽出`

短いテストSfMをすぐ試したいときの固定間隔モードです。指定した `間隔` の画像を素早く書き出すことを優先するため、Step 2の品質確認対象は自動では増えません。

ONにすると `変化補正` はOFFになります。最終本番用の抽出では、必要に応じてOFFに戻して `変化補正` を使ってください。

## 変化補正

`変化補正` は固定間隔の追加オプションです。GUIでは、直前に採用したフレームとのペア解析を使います。抽出の主軸は固定間隔のままにして、解析結果から以下を行います。

- yaw補正後の残差: 360 equirect の横方向シフトを推定し、単なる回転で説明できる差分を抑えてから変化量を測る
- 冗長除外: 固定間隔上の候補でも、直前採用フレームから十分な残差変化がなければ `redundant_drop` として除外
- 追加採用: 固定間隔より前でも、残差変化が十分なら `novelty_added` として追加
- 安全採用: 採用間隔が `最大` に達したら `gap_forced` として採用
- 候補ペアの追跡確認: 採用/除外判断点だけで疎な特徴点追跡を行い、弱い場合は `weak_match` としてStep 2の確認対象にする

### `最小`

- 単位: 秒
- 意味: 追加候補を入れるときの最小間隔
- 内部計算: `min_gap_frames = round(min_gap_sec * fps)`
- デフォルト: `0.25` 秒

どれだけ変化が大きくても、この間隔より近い追加候補は入りません。

### `最大`

- 単位: 秒
- 意味: 低変化スキップで採用フレームが空きすぎないようにする安全間隔
- 内部計算: `max_gap_frames = round(max_gap_sec * fps)`
- デフォルト: `2.0` 秒

変化が少ない区間でも、この間隔以上に離れる候補は安全側で残します。

## 解析幅

### `解析幅`

- 単位: ピクセル
- 意味: yaw補正後残差、候補ペアの特徴点追跡、簡易ブラー確認に使う解析解像度の横幅
- デフォルト: `1920`

値を上げると細かい特徴を見やすくなりますが解析は遅くなります。値を下げると高速になりますが、細かい変化や特徴点を見落としやすくなります。

## ペア解析の確認情報

従来の単体フレーム `SfM品質スコア` と近傍代替フレーム選択は、GUIの通常抽出では使いません。丁寧に撮影された動画では、単体の品質順位よりも「直前採用フレームから見て、重複が残りつつ冗長ではないか」を見る方が切り出し間隔の判断に近いためです。

CSVにはStep 2向けに以下を記録します。

- `residual_score`: yaw補正後の残差変化
- `raw_change_score`: yaw補正前の輝度差
- `yaw_shift_deg`: 推定した横方向のyaw補正量
- `track_count`: 候補ペアで追跡できた特徴点数
- `track_coverage`: 追跡点の画面内カバレッジ
- `match_confidence`: 追跡数とカバレッジから作る確認用信頼度

## 画像形式

### `JPEG品質`

- 単位: ffmpegの `-q:v`
- UI範囲: `1〜31`
- 操作: 数値欄を横ドラッグして調整可能
- 重要: 数値が小さいほど高画質・大容量
- デフォルト: `2`

## 確認の見方

Step 2では `selected_frames.csv` の `status` をもとに確認対象を表示します。

- `ok`: 通常採用
- `novelty_added`: 固定間隔より前だが、直前採用フレームからの残差変化が十分なため追加
- `redundant_drop`: 固定間隔上の候補だが、直前採用フレームからの残差変化が小さいため除外中
- `gap_forced`: `最大` 間隔に達したため安全側で採用
- `weak_match`: 採用したが、候補ペアの特徴点追跡が弱いため確認対象
- `smart_added` / `replaced` / `fallback_keep` / `thinned`: `--analysis-pipeline legacy` で旧解析を使った場合の旧ステータス

まずは固定間隔 `0.8〜1.0` 秒、`変化補正` ONのまま1本抽出し、Step 2で `novelty_added`、`redundant_drop`、`gap_forced`、`weak_match` の出方を見て調整するのが安全です。
