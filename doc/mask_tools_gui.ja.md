# STechDrive 3DGS Utils Step 3 — マスク生成GUI

## 概要

Step 3 は、抽出済みフレームまたは外部から用意した連番画像 (`images/`) から、SfM前に使うマスク (`masks/`) を生成するGUIです。

内部では次のCLIを呼び出します。

- `yolo_mask.py`: YOLO/SAM2.1による主マスク生成
- `sky_mask.py`: Mask2Former ADE20K またはローカルSAM3.1による主マスク生成
- `stitch_mask.py`: スティッチ境界マスク
- `overexposure_mask.py`: 白飛びマスク
- `custom_mask.py`: ユーザー指定PNGマスクのAND合成

## 起動

```bat
run_gui.bat --scene ./scene01
```

## 主な入力項目

- `シーンフォルダ`: ベースフォルダ。Step 3 では `images` / `masks` が自動入力されます。
- `画像フォルダ`: 主マスクと追加マスクの入力画像フォルダ。
- `マスクフォルダ`: 生成マスクの出力先。
- `画像タイプ`:
  - `360°`: エクイレクタングラー360°画像。スティッチ境界と投影補助を使えます。
  - `通常`: 通常画像。スティッチ境界と360°専用の極投影補助を無効化します。
- `追加マスク`: 主マスク生成後に追加する任意工程です。
  - `スティッチ`: 360°画像のスティッチ境界を除外します。
  - `白飛び`: 白飛び画素を除外します。
  - `カスタム`: ユーザー指定PNGマスクを最後にAND合成します。
- 設定タブ:
  - `マスク設定`: 主マスクモデル、検出対象、拡張量、投影補助を設定します。
  - `スティッチ/白飛び`: 追加マスクのスティッチ境界と白飛び設定。
  - `カスタムマスク`: PNGカスタムマスクの読み込みと解除。

## マスク設定

- `モデル`:
  - `YOLO/SAM2.1`: 既定経路。COCOクラスをYOLOで検出し、SAM2.1で形状を整えます。
  - `Mask2Former`: ADE20K semantic segmentation。選択したADE20Kクラスを `sky_mask.py --backend mask2former --labels ...` に渡します。
  - `SAM3.1`: `models/sam3.1/sam3.1_multiplex.pt` がある場合に使えるローカルプロンプトbackendです。
- `品質`: 主マスクモデルへ渡す入力素材レシピです。
  - `標準`: 全体直処理中心。360°画像では軽い下部投影も実行します。
  - `高品質`: 推奨既定。人物向けタイルと、360°画像向けの上部/下部投影補助を追加します。
  - `最高`: より細かいタイルと強い下部補助を使います。
  - 通常画像では全体直処理と全体タイルを使い、360°専用の極投影は使いません。
- `マスク拡張`: 選択中の主マスクbackendに `--expand` として渡します。既定は `0px`、GUI範囲は `-16〜32px` です。
- `YOLO検出クラス一覧`: `YOLO/SAM2.1` 用です。既定は `person` (`id=0`) です。
- `ADE20Kクラス一覧`: `Mask2Former` 用です。既定は `sky` と `person` です。複数クラスは1回の推論でまとめて解決し、最終マスクへ統合します。
- `検出対象`: `SAM3.1` 用です。既定は `person` と `sky` です。チェックボックスとカスタム英語プロンプトを指定できます。
  - SAM3.1では複数プロンプトを1つずつ実行し、結果をOR合成します。
- 投影補助は `品質` に含まれます。
- `推論サイズ`: Mask2Formerの入力サイズです。SAM3.1は現在 `1008` 固定です。
- `モデル詳細`: Mask2Former専用の `最小スコア` (`0.00〜1.00`、`0`で無効) を含みます。
- `空の後処理`: 空だけに適用する調整です。
  - `小領域除去`: 小さな空候補を画像面積比で除去します。
  - `上端接続の空だけ`: 画像上端に接している空だけ残します。
  - これらは空ラベル/空プロンプトだけに適用し、人物など他の対象には適用しません。

## プレビューと再生成

- `マスクプレビュー`: 表示中の画像だけ、一時フォルダに現在設定のマスクを作ります。`masks/` には保存しません。
- 一時プレビュー中はボタンが `プレビュー解除` になり、保存済みマスク表示へ戻せます。
- サムネイル一覧で押した場合は、選択中の画像を1枚プレビューに切り替えて一時マスクを表示します。
- `表示中を再生成`: 表示中の1枚だけ、現在設定で `masks/` へ保存し直します。
- サムネイル一覧では複数選択して `選択N枚を再生成` できます。漏れがあった画像だけ設定変更して直す用途です。

## 実行

`マスク設定` で主マスクモデルと対象を選び、必要な `追加マスク` をONにして `生成` を押します。

実行順は常に、主マスク -> スティッチ -> 白飛び -> カスタムです。既存マスクは現在の設定から再生成され、OFFにした追加マスクの前回結果は残りません。

`selected_frames.csv` がない場合でも、シーンフォルダ内の `images/` に画像があれば外部画像として生成できます。この場合、Step 2 の採用/除外チェックは行われません。

## 補足

- GUIはCLIスクリプトをサブプロセス実行するため、挙動はCLIと揃えています。
- 主マスク機能では、別ライセンスの第三者ライブラリおよびモデル重みを使用します。詳細は [../THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md) を参照してください。
- 実行ログは下部ログパネルで確認できます。
