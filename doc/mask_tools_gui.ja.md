# Step 3 マスク生成GUI

Step 3 は、Step 2で残した `images/` から、SfMや3DGSに使いたくない領域を除外するための `masks/` を作る画面です。人物、撮影者、三脚、手元、車両、空、スティッチ境界、白飛びなどを黒くマスクします。

マスクの約束は、**白=使う、黒=除外**です。Metashape、COLMAP、SphereSfMなどへ渡す前にここでマスクを作ると、SfMで人物や空などの不要な特徴点を拾いにくくできます。

## まず決めること

| やりたいこと | 推奨設定 |
| --- | --- |
| 360°動画から抽出したフレームの人物や撮影者を消したい | `画像タイプ: 360°` と表示されていることを確認し、`モデル: YOLO/SAM2.1`, `品質: 高品質` |
| 人物や空をできるだけ高精度に処理したい | `モデル: SAM3.1` |
| 都市部の道路景観で空・道路・車両・植生などをセマンティッククラスで処理したい | `モデル: YOLO26-sem`、必要なCityscapes対象を選択 |
| 通常カメラの静止画や動画フレームを処理したい | シーンに追加・コピーし、`画像タイプ: 通常` と表示されていることを確認 |
| 追加したばかりのソースだけ処理したい | `ソース` で対象の動画または静止画フォルダを選ぶ |
| 既存マスクを上書きしたくない | `処理範囲: 未作成のみ` |
| マスク設定を変えた画像だけ作り直したい | `処理範囲: 未作成 + 設定変更` |
| 近距離のスティッチ境界が気になる | `スティッチ` ON |
| 窓や照明の白飛びを除外したい | `白飛び` ON |
| 自作の固定マスクを全画像に反映したい | `カスタム` ON |

都市部の道路沿いの360°画像では、`YOLO26-sem` + `高品質` と必要なCityscapesターゲットから始めます。人物のみを高速に処理したい素材では、従来の `YOLO/SAM2.1` も残して使えます。

## 基本操作

1. `画像フォルダ` がシーン内の `images/` を指していることを確認します。
2. `ソース` を確認します。通常は `すべて` のままで構いません。追加したばかりの動画や静止画フォルダだけ処理したい場合は、そのソースを選びます。
3. `処理範囲` を選びます。既存マスクを残したい場合は `未作成のみ`、設定変更を反映したい場合は `未作成 + 設定変更`、全部作り直したい場合だけ `全画像を再生成` を使います。
4. `画像タイプ` 表示を確認します。Step 1の記録、外部画像登録、画像ヘッダー推定から自動判定され、混在時は画像タイプ別に分割処理されます。
5. `モデル` と `検出対象` を選びます。
6. 必要なら `スティッチ`、`白飛び`、`カスタム` をONにします。
7. まず1枚で `マスクプレビュー` を実行し、マスクされる範囲が赤色で重なって表示されることを確認します。
8. 問題なければ `生成` で選択範囲を処理します。
9. サムネイル一覧で漏れや誤検出を探します。
10. 問題がある画像だけ選択し、設定を変えて `マスク再生成` します。

Step 2で除外にした画像がまだ残っている場合や、レビュー対象ではない画像が混ざっている場合は、Step 3の実行前に止まります。先にStep 2で `適用` するか、マスクしたい画像だけが `images/` に残る状態に整理してください。

## モデルの選び方

| モデル | 向いている用途 |
| --- | --- |
| `YOLO/SAM2.1` | COCO物体検出をSAM2.1で輪郭補正する従来ルート。主に人物向け |
| `YOLO26-sem` | 都市部の道路景観向け。空、道路、建物、車両、植生などを高速に処理するCityscapesセマンティックマスク |
| `SAM3.1` | 英語プロンプトで、人物、空、三脚、手、スマホなどを高精度に処理したい場合 |

### YOLO/SAM2.1

人物を高速にマスクしたい場合の推奨ルートです。YOLOで検出対象を見つけ、SAM2.1で形状を整えます。基本は `person` だけを使います。車両などもマスクしたい場合は、必要な対象を `検出対象` から追加できます。

### YOLO26-sem

YOLO26-semは、Cityscapesで学習された都市の道路景観向け19クラスのセマンティックモデルです。画像の各ピクセルにクラスIDを予測するため、SAMによる追加の輪郭補正なしで白黒マスクを作れます。空、道路、建物、車両、植生などを高速にマスク候補化できます。SfMで揺れる木や葉が問題になる場合は `vegetation` をONにします。`building`、`road`、`sidewalk` などの静的特徴は通常OFFのままにしてください。

360°画像では、品質設定が投影補助の強さを決めます。高品質ではエクイレクタングラー直処理に加えて上部/下部投影を合成し、ERPの上下端付近の歪みによる取りこぼしを減らします。

### SAM3.1

固定クラスから選ぶ方式ではなく、英語プロンプトで「何をマスクしたいか」を指示する高精度ルートです。`person`、`sky`、`tripod` のような単語だけでなく、`selfie stick`、`cell phone`、`person wearing a red jacket`、`hand holding a phone`、`tripod legs near the floor` のような短い自然言語フレーズも使えます。画面のチェックボックスは、よく使うプロンプトを手入力せずに追加するための簡易選択です。足りない対象は追加プロンプト欄に英語で入力します。

生成後にマスク漏れや誤検出が残った画像だけ選び、プロンプトと処理方法を組み合わせることで、現在のマスクに範囲を追加したり、SAM3.1内部で `logo` や `sign` などの不要な対象を候補から外したりして効率的に修正できます。

追加プロンプトは、マスクされていない対象を後から拾うために使います。たとえば人物の足元に残った三脚なら `tripod legs near the floor`、手元のスマホなら `hand holding a phone` を入力し、処理方法を `追加` にして該当画像だけ再生成します。除外プロンプトは、SAM3.1の候補マスクから外したい対象を指定するために使います。たとえば案内板の人物アイコンやロゴを候補から外したい場合は `male icon`、`female icon`、`logo`、`sign` などを入力します。

初回利用時に `models/sam3.1/sam3.1_multiplex.pt` がない場合、Hugging Faceのアクセス承認とSAM Licenseへの同意が必要です。GUIからダウンロードする場合は、承認済みアカウントで作った `Read` トークンを使います。このアプリはトークンを保存しません。

## 品質と拡張

`品質` は、精度と処理時間のバランスです。

| 品質 | 使いどころ |
| --- | --- |
| `標準` | 軽い確認用。通常画像ではここから始めてもよい |
| `高品質` | 360°画像の推奨開始点。ERPタイルと上部/下部投影補助を使う |
| `最高` | 漏れが残る画像だけに使う。処理時間は増える |

`マスク拡張` はマスク境界を広げる設定です。値を上げると黒い除外領域が広がります。人物の輪郭や細い対象の端が少し残る場合だけ少し上げ、既定のマスクで十分な場合は `0` のまま使います。

## 処理方法

`処理方法` は、今回生成した候補マスクを既存マスクへどう反映するかを選びます。

| 処理方法 | 動作 |
| --- | --- |
| `置き換え` | 既存マスクを使わず、今回の設定で作り直す |
| `追加` | 今回検出した範囲を既存マスクへ除外領域として追加する |
| `解除` | 今回検出した範囲を既存マスク上で白に戻す |

SAM3.1の追加プロンプト/除外プロンプトは、候補マスクを作るための内部指定です。`処理方法` は、その候補マスクを保存済みマスクへどう反映するかを決める全体設定です。

## オプションマスク

モデルによるマスク生成のあと、必要に応じて追加マスクを合成できます。実行順は常に、モデル -> スティッチ -> 白飛び -> カスタムです。

| オプション | 使う場面 |
| --- | --- |
| `スティッチ` | 360°画像のスティッチ境界を除外したい場合 |
| `白飛び` | 窓、照明、反射などの白飛びを除外したい場合 |
| `カスタム` | 自作PNGマスクを全画像に反映したい場合 |

スティッチ境界がほとんど見えない素材では、スティッチマスクはOFFまたは細めから試します。方向ロック、手ブレ補正、AIスティッチなどで境界位置が動く素材では、通常OFFにしてください。

カスタムマスクはPNGを使います。白が使う領域、黒が除外領域です。画像サイズが一致する入力にだけ適用されます。

## プレビューと再生成

### マスクプレビュー

`マスクプレビュー` は、表示中の1枚だけ現在設定で一時マスクを作ります。`masks/` には保存しません。まずここで漏れや消しすぎを確認します。

`プレビュー表示` で、一時プレビューと保存済みマスク表示を切り替えられます。360°画像では、パース表示に切り替えると足元、三脚、人物の輪郭、スティッチ付近を確認しやすくなります。

### マスク再生成

`マスク再生成` は、表示中の1枚、またはサムネイル一覧で選択した複数枚だけを現在設定と処理方法で `masks/` に保存します。

最初から全画像を最高品質で処理するより、まず標準/高品質で全体を作り、漏れがある画像だけ再生成するほうが効率的です。

## 実行後にできるもの

| 出力 | 内容 |
| --- | --- |
| `masks/` | `images/` に対応するマスク画像 |
| 一時プレビュー | 表示確認用。保存マスクではない |
| 実行ログ | 下部ログパネルに表示 |

生成済みの `masks/` は、MetashapeやCOLMAP/SphereSfMにマスクとして読み込ませるか、Step 5のデータセット作成で学習用画像に合わせたマスクへ変換します。マスク極性は白=使う、黒=除外です。

## よくある判断

- 都市部の道路景観では、まず `YOLO26-sem` + `高品質` で、空・車両・植生など必要なCityscapes対象を処理します。
- 特定の素材で従来のCOCO人物/物体ルートが合う場合は `YOLO/SAM2.1` を使います。
- 三脚、手、自撮り棒、スマホ、プロンプトによる細かい修正が必要な場合は `SAM3.1` を使います。
- 360°画像の下部に撮影者や三脚が残る場合は、品質を上げるかSAM3.1で `tripod`、`hand`、`selfie stick` などを指定し、マスク範囲に追加します。
- 白飛びは消しすぎる場合があるので、必要な素材だけONにします。
- 通常画像ではスティッチ境界と360°専用の投影補助は使いません。
- 既に確認済みのマスクを残したい場合は `未作成のみ` を使います。
- 設定を変えた後に差分だけ更新したい場合は `未作成 + 設定変更` を使います。
- 新しいソースを追加した直後は、`ソース` でその追加分だけに絞ると確認しやすくなります。
- GPUメモリ不足でSAM3.1が止まっても、完了済みマスクは残ります。同じ設定で再実行すると未処理画像から再開します。
