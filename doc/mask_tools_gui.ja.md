# STechDrive 3DGS Utils Step 3 — マスク生成GUI

## 概要

Step 3 は、抽出済みフレームまたは外部から用意した連番画像 (`images/`) から、SfM前に使うマスク (`masks/`) を生成するGUIです。

内部では次のCLIを呼び出します。

- `yolo_mask.py`: YOLO/SAM2.1によるモデルベースのマスク生成
- `sky_mask.py`: Mask2Former ADE20K またはSAM3.1によるマスク生成
- `stitch_mask.py`: スティッチ境界マスク
- `overexposure_mask.py`: 白飛びマスク
- `custom_mask.py`: ユーザー指定PNGマスクのAND合成

## 起動

```bat
run_gui.bat --scene ./scene01
```

## 主な入力項目

- `シーンフォルダ`: ベースフォルダ。Step 3 では `images` / `masks` が自動入力されます。
- `画像フォルダ`: マスク生成の入力画像フォルダ。行の右端の `+` アイコンで、別フォルダ内の対応画像を現在のシーンの `images/` にコピーできます。
  - `シーンフォルダ` が未指定の場合は、先にシーンフォルダの選択を求めます。
  - コピー対象は選択フォルダ直下の画像ファイルだけです。サブフォルダは走査しません。
  - `images/` に同名ファイルがある場合はスキップし、上書きしません。
  - `selected_frames.csv` が既にあるシーンでは、コピーした画像はCSVに自動追加されません。生成前に未追跡画像として止まるため、CSVと画像の不一致を解消するか、外部連番画像用に別シーンを使ってください。
- `マスクフォルダ`: 生成マスクの出力先。
- `画像タイプ`:
  - `360°`: エクイレクタングラー360°画像を処理するときに選びます。
  - `通常`: 通常の動画フレームや静止画を処理するときに選びます。
  - 画像タイプが混在する場合は、フォルダを分けてそれぞれ処理してください。
- `オプション`: モデルによるマスク生成後に追加する任意工程です。
  - `スティッチ`: 360°画像のスティッチ境界を除外します。
  - `白飛び`: 白飛び画素を除外します。
  - `カスタム`: ユーザー指定PNGマスクを最後にAND合成します。カスタムマスク行のファイルアイコンで選択し、削除アイコンで解除できます。
- 設定タブ:
  - `マスク設定`: マスク生成モデル、検出対象、拡張量、投影補助を設定します。
  - `オプション`: スティッチ境界、白飛び、PNGカスタムマスクの設定。

## マスク設定

- `モデル`:
  - `YOLO/SAM2.1`: 既定経路。COCOクラスをYOLOで検出し、SAM2.1で形状を整えます。
  - `Mask2Former`: ADE20K semantic segmentation。選択したADE20Kクラスを `sky_mask.py --backend mask2former --labels ...` に渡します。
  - `SAM3.1`: プロンプトでマスクを生成します。`models/sam3.1/sam3.1_multiplex.pt` が無い場合、Hugging Faceの利用承認後にGUIからダウンロードできます。
    ブラウザで `facebook/sam3.1` のFilesタブや `sam3.1_multiplex.pt` を開ける/ダウンロードできる場合、そのHugging Faceアカウントでは承認済みです。GUIからのダウンロードには、同じアカウントで作成した `Read` トークンを使ってください。トークンは作成直後にコピーし、Issue、チャット、スクリーンショット、ログなどへ貼らないでください。このアプリはトークンを保存しません。
- `品質`: 精度と処理時間のバランスを選びます。
  - `標準`: 全体直処理中心。360°画像では軽い下部投影も実行します。
  - `高品質`: 推奨既定。人物向けタイルと、360°画像向けの上部/下部投影補助を追加します。
  - `最高`: より細かいタイルと強い下部補助を使います。
  - 通常画像では全体直処理と全体タイルを使い、360°専用の極投影は使いません。
  - まず `標準` または `高品質` で生成し、漏れがある画像だけ選択して品質を上げて再生成できます。
- `マスク拡張`: 選択中のbackendに `--expand` として渡します。正の値でマスクする範囲を広げ、負の値で狭めます。既定は `0px`、GUI範囲は `-16〜32px` です。
- `検出対象`: `YOLO/SAM2.1` 用ではCOCOクラスを選びます。既定は `person` (`id=0`) です。
- `検出対象`: `Mask2Former` 用ではADE20Kクラスを選びます。既定は `sky` と `person` です。複数クラスは1回の推論でまとめて解決し、最終マスクへ統合します。
- `検出対象`: `SAM3.1` 用ではプロンプトを選びます。既定は `person` と `sky` です。チェックボックスとカスタム英語プロンプトを指定できます。
  - SAM3.1では複数プロンプトを1つずつ実行し、結果をOR合成します。
  - カスタムプロンプト欄はカンマ、セミコロン、改行で区切れます。区切り文字前後の半角スペースは無視し、`selfie stick` のような語内スペースは保持します。
  - 減算プロンプト欄は、SAM3.1の肯定側検出結果から該当プロンプトの検出領域を差し引きます。
- `適用` はSAM3.1専用で、`品質`、`拡張` と同じ行に表示されます。`再生成` は今回の検出結果で書き直し、`加算` は既存マスクに検出領域を黒で追加し、`減算` は既存マスク上の検出領域を白に戻します。
- 投影補助は `品質` に含まれます。
- `推論サイズ`: 大きいほど細部や境界が安定しやすくなりますが、GPUメモリと処理時間が増えます。GUIで変更できるのはMask2Formerだけで、YOLO/SAM2.1とSAM3.1は固定サイズです。
- `モデル詳細`: Mask2Former専用の `最小スコア` (`0.00〜1.00`、`0`で無効) を含みます。
- `空マスク設定`: 空だけに適用する調整です。
  - `小領域除去`: 小さな空候補を画像面積比で除去します。
  - `上端接続の空だけ`: 画像上端に接している空だけ残します。
  - これらは空ラベル/空プロンプトだけに適用し、人物など他の対象には適用しません。

## プレビューと再生成

- `マスクプレビュー`: 表示中の画像だけ、一時フォルダに現在設定のマスクを作ります。`masks/` には保存しません。
- SAM3.1の `加算` / `減算` モードでは、保存済みマスクを一時フォルダにコピーしてからプレビューするため、既存マスクへの補正結果を確認できます。
- `プレビュー表示` で、生成済みの一時プレビューと `masks/` に保存済みのマスク表示を切り替えられます。一時プレビューは削除されません。
- サムネイル一覧で押した場合は、選択中の画像を1枚プレビューに切り替えて一時マスクを表示します。
- `マスク再生成`: 表示中の1枚だけ、現在設定で `masks/` へ保存し直します。SAM3.1の `加算` / `減算` モードでは、既存マスクへ現在の検出結果を適用します。
- サムネイル一覧では複数選択して `マスクN枚再生成` できます。漏れがあった画像だけ設定変更して直す用途です。

## 実行

`マスク設定` でマスク生成モデルと対象を選び、必要な `オプション` をONにして `生成` を押します。

実行順は常に、モデルによるマスク生成 -> スティッチ -> 白飛び -> カスタムです。既存マスクは現在の設定から再生成され、OFFにした追加マスクの前回結果は残りません。

SAM3.1の一括生成では途中保存/未処理再開つきで実行します。GPUメモリ不足で停止しても完了済みマスクは残り、同じ設定で再実行すると未処理画像から続行します。

`selected_frames.csv` がない場合でも、シーンフォルダ内の `images/` に画像があれば外部画像として生成できます。この場合、Step 2 の採用/除外チェックは行われません。
`selected_frames.csv` がある場合は、生成前に `images/` とCSVの整合性を確認し、除外予定の画像やCSVにない画像が残っていると停止します。

## 補足

- GUIはCLIスクリプトをサブプロセス実行するため、挙動はCLIと揃えています。
- セマンティック/人物マスク機能では、別ライセンスの第三者ライブラリおよびモデル重みを使用します。詳細は [../THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md) を参照してください。
- 実行ログは下部ログパネルで確認できます。
