# custom_mask.py — 静的PNGマスクの合成

`custom_mask.py` は、ユーザーが用意した1枚のPNGマスクを、シーン内の
マスクへAND合成します。

マスク規約は、このプロジェクトの他のマスク処理と同じです。

- 白 (`255`) = 採用 / 使用するピクセル
- 黒 (`0`) = 除外 / マスクするピクセル

## 使い方

```bash
python -m core.custom_mask ./scene01/images ./scene01/masks ./custom_mask.png
```

引数:

| 引数 | 内容 |
| --- | --- |
| `images_dir` | 入力画像フォルダ。サブフォルダも再帰的に処理します。 |
| `masks_dir` | マスク出力フォルダ。既存マスクの読み込み先/書き戻し先です。 |
| `custom_mask` | 各入力画像に適用するPNGマスク。画像と同じサイズの場合だけ適用されます。 |

オプション:

| オプション | 内容 |
| --- | --- |
| `--replace` | 既存マスクを無視して、カスタムマスクだけの出力を書き込みます。 |

入力画像の対応拡張子は `.jpg`, `.jpeg`, `.png`, `.tif`, `.tiff` です。

## 入力マスクの規則

- カスタムマスクはPNGのみです。
- 8bit/16bitのグレースケール、RGB、RGBA PNGを受け付けます。
- RGB/RGBAはグレースケール化します。アルファは無視します。
- 8bit値は `128` 以上を白、それ未満を黒にします。
- 16bit値は `32768` 以上を白、それ未満を黒にします。
- カスタムマスクはリサイズしません。入力画像と幅・高さが一致する場合だけ適用します。

## 出力動作

- 出力マスクのサブフォルダ構造は、入力画像の構造を `masks_dir` 以下に反映します。
- 出力ファイル名は入力画像のstemに `.png` を付けます。例:
  `images/a/frame_0001.jpg` -> `masks/a/frame_0001.png`
- 対応する既存マスクがある場合は、`既存マスク AND カスタムマスク` を書き込みます。
- 既存マスクがない場合、または `--replace` 指定時は、カスタムマスク自体を書き込みます。
- サイズが一致しない画像はスキップします。
- 入力画像が存在するのに1枚もサイズ一致しなかった場合は、エラー終了します。

統合GUIでは、カスタムマスク工程は選択中のモデルによるマスク生成、スティッチ境界、白飛びの後に実行されます。
そのため、最後にAND合成する仕上げ工程として動作します。
