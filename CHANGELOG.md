# Changelog

All notable changes follow Keep a Changelog and semantic versioning.

## [Unreleased]

- Continue workstation-shell, component-manager, updater-signing, recovery and installer work toward v0.2–v0.9.

## [0.1.0-dev.1] - 2026-09-03

### Added

- First Windows development preview with a portable ZIP and Inno Setup installer.
- Deterministic SHA-256 checksum list, release manifest, SBOM, and bundled license notices.
- Frozen desktop/CLI smoke tests and isolated DLL collection for reproducible packaging.

## [0.1.0] - 2026-09-02

### Added

- Independent 360GS Studio package, CLI and Midnight workstation shell.
- Versioned project, view, job, component, language and theme contracts.
- Non-destructive `_stechdrive` to `_360gs` project migration and rollback.
- Persistent jobs with interrupted-run recovery.
- FFmpeg, COLMAP and external-trainer adapter boundary plus hardware diagnostics.
- Shared cached projection engine and bounded multi-view FFmpeg batches.
- Perspective Export workspace with globe selection, editable views, previews,
  presets, PNG/JPEG/HEVC export and COLMAP rigs.
- Component registry, checksum/license-gated installer, CI, Windows packaging,
  issue forms, ADRs and provenance notices.
