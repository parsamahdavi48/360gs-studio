# External Tools

360GS Studio integrates with tools you install separately:

- **FFmpeg/FFprobe** — decoding, filtering, and encoding.
- **COLMAP** — cubemap-rig or native equirectangular SfM.
- **Metashape** — external camera alignment and point-cloud export.
- **RealityScan** — realignment and conversion workflows.
- **LichtFeld Studio, Postshot, Brush, and gsplat** — external training and inspection.

Commercial trainers are never downloaded automatically. Select their executable or environment in the application. Use `360gs-studio doctor` to inspect detected capabilities.
